// live product

Samachar: Ad-free & multilingual news, built for ALL.

An open-source Indian news aggregator PWA. Pulls live from The Hindu, Indian Express, BBC Hindi, and Dainik Bhaskar via RSS - no ads, no tracking, works offline.

  • Vanilla JS, HTML, CSS - no framework, no build step, by design.
  • Node.js serverless function on Vercel, hand-written RSS/XML parsing via regex, no external XML library.
  • SSRF-hardened fetch layer: blocks private/loopback/link-local IPs and AWS metadata ranges, caps redirects, enforces HTTPS.
  • Per-IP rate limiting, HTML-escaping on all rendered content and CSS-class allowlisting to prevent injection.
  • A+ security rating - full header suite (CSP, HSTS w/ preload, X-Frame-Options, COOP, CORP, Permissions-Policy).
  • Service worker with network-first caching; installable, works offline.
